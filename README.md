# ScootGoal

Адаптивное приложение для личных целей накопления и учёта заработка. Node.js + Express + SQLite, регистрация и вход по email/паролю.

## Возможности
- Регистрация, вход и выход из аккаунта.
- Отдельные цели, пополнения/снятия, история операций и история рабочих смен у каждого аккаунта.
- Цели с датой и необязательным планом накопления в день, неделю или месяц.
- Учёт смен: номер, дата, ставка, часы, заметка и автоматический расчёт заработка.
- Экспорт/импорт резервной копии конкретного аккаунта.
- Пароли хранятся в виде scrypt-хеша с отдельной случайной солью; сессия хранится в подписанной HttpOnly cookie.

## Локальный запуск
Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

Откройте http://localhost:3000 и создайте аккаунт.

## Деплой на Render через GitHub
1. Создайте новый публичный или приватный репозиторий на GitHub и загрузите **содержимое этой папки** в корень репозитория (`server.js`, `package.json`, `render.yaml`, `public/`). Не загружайте `node_modules`, `scootgoal.db` или `.env`.
2. В Render выберите **New + → Blueprint**, подключите репозиторий и примените `render.yaml`.
3. Blueprint настраивает Node-сервис, переменную `SESSION_SECRET` и постоянный диск SQLite в `/var/data`.
4. После завершения деплоя откройте выданный Render URL и создайте свой аккаунт. Ссылку можно отправить друзьям — каждый зарегистрирует свой аккаунт.

**Стоимость:** для сохранения SQLite между перезапусками нужен постоянный диск Render; Render может требовать платный план для сервиса с диском. Перед подтверждением проверьте актуальную стоимость на странице Render. Не удаляйте диск, если хотите сохранить данные.

## Переменные окружения
- `PORT` — Render задаёт автоматически.
- `NODE_ENV=production` — включает Secure-флаг cookie.
- `SESSION_SECRET` — Render генерирует через Blueprint; храните в секрете.
- `DB_PATH=/var/data/scootgoal.db` — база на постоянном диске.

## Важно
- Все API для целей и заработка требуют входа. Запросы всегда ограничиваются ID текущего пользователя.
- Экспортируйте резервные копии время от времени.
- Не публикуйте файл базы данных, пароли или значения секретов в GitHub.
